# Invoice Agent

A clickable prototype of an SAP Ariba invoice processing experience with a Joule AI assistant panel.

## Live Demo

**👉 [https://pages.github.tools.sap/I515936/invoice-agent/invoice-agent.html](https://pages.github.tools.sap/I515936/invoice-agent/invoice-agent.html)**

## What This Is

A single-file HTML prototype demonstrating how an AI-powered invoice agent (Joule) can guide a user through invoice processing — from search → typeahead → Joule conversation → invoice selection → approval submission.

Built for demo and presentation to SAP stakeholders.

## Design System

- **Theme:** SAP Horizon Morning
- **Font:** `'72', 'Segoe UI', Arial, sans-serif`
- **Spacing base:** 8px

## How to Run Locally

Simply open `invoice-agent.html` in any browser — no build step or dependencies required.
